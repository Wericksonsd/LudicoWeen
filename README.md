## Instalação e execução
É necessário node v24.21.0 ou superior
É necessária o npm versão 12.2.0 ou superior

No terminal, execute:

```bash
  #para acessar a pasta do app
  cd my-app

  #Instalar as dependências
  npm install

  #Iniciar o ambiente de desenvolvimento
  npm run dev
```
Depois dessas etapas, abra o http://localhost:3000 no seu navegador, de preferência desabilite qualquer extensão que poderá interferir na compilação, ou abra em uma guia anônima.
